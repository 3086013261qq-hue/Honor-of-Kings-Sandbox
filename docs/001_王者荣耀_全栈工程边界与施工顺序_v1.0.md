# 王者荣耀｜咩咩制卡包·全栈工程边界与施工顺序 v1.0

## 项目定位
- 唯一仓库：3086013261qq-hue/Honor-of-Kings-Sandbox；branch：main；Public。
- 舞台：**王者大陆原著世界**，以原著剧情线为锚点进行沙盒扮演；不是王者峡谷 5v5 竞技复刻。
- 世界书采用咩咩制卡包·全栈既有分层，不重写咩咩预设，不擅自另造世界运行机制。
- **时间线简单分卷**：每卷对应一条经核验的原著剧情线；不做跨区域同步发展、事件导演或强制任务链。玩家可以自由介入，改变后续事件。
- 时间线标记沿用用户约定：`YYYY年MM月DD日 + 卷内 A/B/C 编号`；不凭空捏造官方纪年；原著只给相对时间时先保留相对顺序，待确认后再定沙盒日期。

## 特有玩法：英雄皮肤切换
- 每名正式英雄有**经典原皮**与**一套精选高品质皮肤**。
- 优先选符合要求的传说皮肤；没有传说时从史诗等现有皮肤中选最具代表性／高人气者。最终名单另行核对并由用户确定。
- 沿用 BS1 已验证的 MVU → 世界书条目开关方案；同一英雄的两套皮肤状态互斥。
- 基础英雄身份、官方关系与核心能力不因换肤意外被覆盖；皮肤专属外貌、服饰、技能表现与明确独立宇宙的剧情区分处理，禁止混淆正史。
- MVU 不在剧情线目录核验前开工；不造全新 MVU 底层。

## 分区
- `worldbook/blue/`：常驻世界底层设定
- `worldbook/green/`：场景/规则按需触发
- `worldbook/characters/`：正式英雄人物
- `worldbook/abilities/`：与人物同源触发的能力
- `worldbook/timeline/`：独立分卷剧情线
- `worldbook/locations/`：地点
- `worldbook/skins/`：互斥皮肤设定世界书条目
- `mvu/`：成熟 MVU 的适配层
- `assets/`：允许公开存储的素材及来源信息
- `qa/`：文献核对、装卡和实机 QA

## 当前施工顺序
1. 逐条核对官方剧情线清单、卷目边界、事件及资料来源；先目录后正文。
2. 蓝灯拟定与精修、冻结，然后按蓝灯展开绿灯。
3. 人物及能力独立层，原著资料校对。
4. 各卷正式时间线与地点正文。
5. 皮肤目录冻结，再做 MVU 适配和媒体资源。
6. 正式装卡及 Android / SillyTavern 实机 QA。
