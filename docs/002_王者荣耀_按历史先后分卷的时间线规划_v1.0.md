# 002｜王者荣耀：按王者大陆世界内历史排序的时间线候选规划 v1.0

状态：候选历史轴 / 未封版 / 未开始逐日正式正文
优先级：本文件关于时间线的约定高于 docs/001 旧版“每卷对应赛年剧情”的表述。此处仅规划历史顺序，不做MVU或角色制作。

## 一、最高原则
1. **以王者大陆内部历史、事件因果为依据**，而不是版本更新／赛季发表顺序，更不是现实中国秦汉唐时间。
2. 几卷即几条简单时间线；只在卷内记录事件先后，沙盒扮演可以自由改写后续结果。**不做跨地区同步发展机制**。
3. 历史上先发生的时代放前面；地区间未有可靠先后依据的事件，只列为同一历史阶段的待排事件，禁止凭空串接。
4. 严禁把皮肤平行世界、二创小说、KPL联动与正式王者大陆正史混写。旧版被新设定修改的资料，建立版本差异备注，优先核查较新的官方游戏内说明。
5. 正式时间线沿用 `YYYY年MM月DD日 + 卷内 A/B/C 编号` 的条目格式，但**王者大陆没有经过核实的公历日期时绝不伪称官方纪年**。卷/事件可先保存“相对年代 + 前后锚点”，正式写卡时如采用自定沙盒历法，明确标明为本卡运行历法。

## 二、暂拟六卷：以世界内历史时期划卷，不以赛季划卷

### 第一卷｜方舟降临与创世（远古）
- 前文明遭遇灾变，幸存者以方舟来到王者大陆。
- 掌握超常知识的“神明”建立新的秩序、发展人类与技术。
- 方舟核心、魔道、机关术、十二奇迹及日之塔属于此阶段的重要历史基础。
- 顺序锚：旧文明灾变 → 方舟到来 → 新秩序/奇迹建造。
- 时代细节需和当前官方版本核对。

### 第二卷｜魔种反抗与诸神黄昏（远古末期）
- 原住魔种在神明统治下遭到役使与伤害，反抗逐步爆发。
- 日之塔能源采集带来的危机及围绕其处置的分歧扩大。
- 女娲与帝俊的对立、诸神战争、方舟核心的封印，标志一个时代的结束。
- 顺序锚：统治矛盾积累 → 魔种起义/日之塔危机 → 诸神冲突 → 核心封印。
- 不抢先断言所有英雄个人经历的具体前后。

### 第三卷｜人类文明与古国兴亡（诸神之后）
- 神明退场后出现历史断层，人类社会逐渐独立发展。
- 古代国家与文明，如朝歌及云中早期文明等，分别兴起、衰落。
- 此卷关注古文明遗产与王者大陆后来政治／魔道制度的起源。
- 顺序锚：诸神时代终结 → 人类独立建制 → 古文明起落。
- 对于具体古国年代与先后未证实者保留待核。

### 第四卷｜诸国并起与群雄逐鹿（较近的历史）
- 古老文明的遗产与地区争端催生新的城邦、政权及联盟。
- 玄雍、三分之地、长城与河洛等势力的成立、战争和重要历史转折，按各自的已知因果整理。
- 如赤壁之战、长城守卫体系成型等事件必须找到各自来源后再放到具体时间节点。
- **不允许仅因嬴政、曹操、武则天的现实历史原型而指定先后**。
- 本卷仅确认大时代位置，跨地区细节待审。

### 第五卷｜英雄时代·各地既有事件（当前世界的前史）
- 稷下学院、人类各国、长城守卫军与长安等现有势力形成可以开展沙盒扮演的背景。
- 聚焦正式英雄的已发生经历、关系变化、势力纷争，以及后续故事发生的前提。
- 长安／三分之地／云中漠地／海都／云梦泽等地区历史，只在有事件因果与出处时确立前后。
- **该卷不按地图地点排时间，也不把相对同时代的事件硬写成先后。**

### 第六卷｜当代王者大陆·连续剧情（最近的主线时期）
- 以已有明确剧情因果的地区连续故事形成卷内时间锚点。
- 长安《凤仪之诏》相关往事、上元夜危机与《不夜长安》相关事件，需先核验确切衔接；
- 云中漠地、海都、云梦泽及后续故事分别校核其内部先后，再决定是否能进入同一条连续卷线。
- **赛季/活动推出时间只用于找素材，绝不作为事件日期证据。**
- 2025—2026仍在延伸、缺乏结局的部分只作后续候选，不强行写成已完结历史。

> 以上卷目为工程建议，不是官方卷名；最终卷数和位置以剧情证据为准，可合并或拆分，但不得倒置已确定的历史因果。

## 三、确认程度
- 已较有依据的宏观顺序：前文明/方舟 → 神明统治与十二奇迹 → 魔种反抗、诸神之战 → 神权衰退 → 人类文明与诸国兴起 → 英雄时代。
- 存在争议或尚未确认：古代各国之间的精确建立/覆灭先后、玄雍/三分/长安之间的公历对应、当代不同地区故事的绝对相对顺序，以及后续新版设定的追认改写。
- 尚无可靠官方公历锚点：不得把“距今若干年”或现实朝代直接变成正式角色卡日期。

## 四、后续逐事件审查方法
- 每条待入卷事件必须记录：世界内发生条件、前置事件、事件结果、涉及英雄/地区、来源链接、是否来自旧设定、是否与新版冲突。
- 顺序确定分三档：A=官方明确先后；B=官方叙述能推出的前后；C=仅推测/未核实（不能写进正式时间线）。
- 首先补全第一、二卷事件目录，再继续第三至六卷；各卷先“目录→逐条考证→正式时间线正文→QA”。
- 不做跨地区独立时间轴引擎，也不引入官方赛季卷名作为主目录。
